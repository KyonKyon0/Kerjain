## UI/UX Requirements
- Design Style: Friendly Local Service Marketplace
- Mobile-first approach
- Must be fully responsive on Mobile, Tablet, and Desktop
- Maintain consistent spacing, typography, colors, and components across all breakpoints
- Do not create separate visual styles for different devices; only adapt the layout responsively
- Optimize navigation and interactions for both touch devices and desktop users
- Ensure accessibility and usability across all screen sizes
